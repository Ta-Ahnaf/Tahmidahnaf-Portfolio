# MD Tahmid Ahnaf — RAW SIGNAL Portfolio

A dependency-free, multi-page creative portfolio built as a static website.

## Open locally

Open `index.html` in a modern browser. All portfolio pages, images, interactions, and the downloadable CV are included in the folder. No installation or build step is required.

For the most consistent local routing and browser behavior, the folder can also be served with any static web server.

## Pages

- `index.html` — entrance, manifesto, selected projects, range, and contact
- `work.html` — expanded AI, machine-learning, Python, and web case files
- `story.html` — profile, Renault PropTech LTD experience, education, skills, and achievement archive
- `notebook.html` — hobbies, personal writing, and creative personality

## Assets

- `assets/css/style.css` — full responsive visual system
- `assets/js/main.js` — loader, fixed LED-style skill board, playful coding loop, navigation, transitions, restrained magnetic motion, and notebook interactions
- `assets/img/` — graphite portrait, the single full-collection trophy archive, and monochrome social preview
- `assets/documents/Tahmid_Ahnaf_Premium_Interactive_CV.pdf` — current downloadable CV

The experience includes accessible navigation, keyboard focus, a skip link, a skippable intro, touch-safe behavior, and a reduced-motion mode.

The research and creative-direction rationale is documented in `docs/CREATIVE_DIRECTION.md`.
